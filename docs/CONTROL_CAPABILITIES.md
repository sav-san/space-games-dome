# Возможность управления ЧПУ и принтером

Проверено по предоставленному 01_API.md, разделы 5.2, 5.3, 7.1, 7.6 и таблицы устройств. Подключение к физическому серверу из этой среды не выполнялось. Практическая работоспособность команд не проверена.

Оба устройства управляются через тот же WebSocket API: сообщение type=control, request_id, node_id, action, value. Доступ зависит от роли team и актуального describe_nodes. Вкладка GUI «Возможности API» показывает ответ текущего сервера для этих устройств; пустой каталог не означает отсутствия поддержки в API.

| Устройство | Действия по документации |
|---|---|
| printer_3d_01 | home, start_job, resume, upload_file, delete_file, set_speed, move |
| cnc_01 | home, start_job, resume, move, set_zero, probe_z |

Оба устройства поддерживают query list_files; для ЧПУ params={"validate": true} позволяет проверить G-code. Точные параметры команд — в 01_API.md.

В описанном режиме исходной документации агенту не доступны пауза, отмена и произвольные команды G-code; текущие разрешения уточняются через describe_nodes. Физические операции выполняет Оператор. После start_job / resume и других команд нужно подтверждать результат новой телеметрией: success означает принятие, а не физическое завершение.

Перед возобновлением требуется устранить hold_reason: три безуспешных resume приводят к ALARM на 20 минут. Перед печатью проверяют bed_clear и защитные условия; перед перемещениями и запуском ЧПУ — homed, координаты, рабочий ноль и состояние станка. Рабочие ограничения нельзя обходить.

В v04 добавлен исполнитель подтверждённых команд чата: turn_on/turn_off, line_on/line_off, home, start_job, resume, move, set_zero, set_speed. Перечень возможностей API шире реализованного исполнителя. Каталог проверяется перед отправкой, затем проверяется новая телеметрия. Автодиагностика не может запускать исполнитель. Подробности и ограничения — в README.md, раздел v04.

## Актуальное поведение v08

Исполнитель поддерживает pause/abort, только если они явно доступны в controls актуального describe_nodes. При отсутствии этих прав остановка требует оператора или изменения серверных прав; снятие питания с работающего станка не используется как замена. Независимые линии доступны при работе производства. Планы до восьми шагов выполняются последовательно с проверкой каждого результата. Подробности — README.md и FIX_v08.md.
